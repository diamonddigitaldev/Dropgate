A Dropgate link. Adding it reads its list of files; nothing is downloaded or counted until you press Download.
Paste a link above to add a download.

A new upload starts on the default server, with that server's settings, and so does Share with Dropgate. Servers are tried in this order when an upload allows fallback. Each server is checked only when it's used.

Saved servers are kept in the app's settings on this computer: Each one's address, name, order and settings for new uploads. What a check finds is kept in memory only.

New downloads will be saved here: The system's Downloads folder unless you choose another. Each download can choose its own.

File lifetime and max downloads for new uploads are each server's own, in Servers.
